Quick Deployment

Clone Repository

$ git clone https://github.com/ultimate-media-server.git
$ cd ultimate-media-server

Configure Environment

$ cp .env.example .env
$ nano .env # Set your API keys

Deploy Stack

$ docker compose up -d
$ open http://localhost:3001

API Integration

MCP Server Endpoints

Jellyfin MCP (Port 3001)
GET /health - Health check
GET /events - SSE stream
POST /call/search_media
POST /call/get_libraries

Sonarr MCP (Port 3002)
POST /call/search_series
POST /call/add_series
GET /call/get_queue

AI Agent Voting (Port 8090)
POST /api/chat
GET /api/agents
GET /api/vote/:id

Example Usage

Search Movies:
curl -X POST http://localhost:3003/call/search_movies \
  -H "Content-Type: application/json" \
  -d '{"arguments": {"term": "Inception"}}'

AI Decision:
curl -X POST http://localhost:8090/api/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "Should I upgrade storage?"}'

Real-time Events:
curl -N -H "Accept: text/event-stream" \
  http://localhost:3001/events

Troubleshooting Guide

Common Issues

❌ Services Not Starting

$ docker ps
$ docker compose logs -f
$ docker compose restart

❌ Can't Access Web UI

$ sudo ufw allow 8096
$ curl http://localhost:8096
$ docker exec jellyfin curl localhost:8096

Health Checks

✅ System Status

$ ./scripts/health-check.sh
$ docker ps --format "table {{.Names}}\t{{.Status}}"
$ curl http://localhost:3001/health

✅ Performance Monitoring

$ docker stats
$ curl http://localhost:9090/metrics
$ open http://localhost:3000
