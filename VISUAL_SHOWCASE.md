## 📱 Installation & Usage

### To View the Modern UI:

1. **Open Landing Page**:
   ```bash
   open modern-landing.html
   # Or in browser: file:///path/to/modern-landing.html
   ```

2. **Access Dashboard**:
   ```bash
   open dashboard-enhanced.html
   ```

3. **Test Mobile View**:
   - Open Chrome DevTools (F12)
   - Toggle device toolbar (Ctrl+Shift+M)
   - Select iPhone or Android device

4. **Test Social Sharing**:
   - Hover over any media item
   - Click share button
   - Select platform
