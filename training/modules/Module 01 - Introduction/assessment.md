## Knowledge Check (Short Answer)

1) In one sentence, state the goal of the basic task.

2) List the minimal steps to complete it successfully.

3) Where can you find troubleshooting guidance?

## Practical Task

Perform the basic task end-to-end and capture proof (screenshot or output). If blocked, write what you tried and where it failed.

Success criteria:

- Correct steps in order
- Sensible error handling if something goes wrong
- Clear, reproducible result
