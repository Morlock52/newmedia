# Quick Reference — Module 01

Keep this handy during demos and practice.

## Common Steps

1. Start local server / open environment
2. Navigate to the primary workflow
3. Execute the minimal steps
4. Verify output and logs

## Helpful Commands

```
# Example
python3 -m http.server 8080

# Check a port in use (macOS)
lsof -i :8080
```

## Troubleshooting

- Restart the service; check logs
- Validate environment variables
- Compare to the known-good example
- Ask for help: share error and what you tried
