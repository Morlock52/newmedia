## 🛠️ Complete Unified Tool Set

### 🎛️ **Unified Management Tools**
- `unified_health_check` - Check all services at once
- `unified_restart_all` - Restart all services (with confirmation)
- `unified_backup_configs` - Backup all configurations
- `unified_sync_libraries` - Synchronize between services
- `unified_get_statistics` - Comprehensive system stats

### 🐳 **Docker Management Tools**
- `docker_list_containers` - List all containers with status
- `docker_container_logs` - Get logs from any container
- `docker_restart_container` - Restart specific containers

### 📺 **Media Service Tools**

**For Each Service (Sonarr, Radarr, Lidarr, etc.):**
- `{service}_status` - Get service health and status
- `{service}_api_call` - Make custom API calls
- `{service}_add_media` - Add new content
- `{service}_get_media` - Retrieve library data
- `{service}_search` - Search for content

**Specialized Tools:**
- **Jellyfin**: Library management, scanning, item retrieval
- **Prowlarr**: Indexer management and cross-indexer search
