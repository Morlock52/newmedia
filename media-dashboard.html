⚡ Quick Setup Guide

1 Jellyfin: Complete setup wizard, create admin user (admin/admin123)
2 Prowlarr: Add indexers (1337x, TPB, etc.), then sync to Sonarr/Radarr
3 Sonarr: Set root folder to /media/tv, add qBittorrent as download client
4 Radarr: Set root folder to /media/movies, add qBittorrent as download client
5 qBittorrent: Login with admin/adminadmin, configure download paths
