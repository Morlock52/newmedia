🛠️Troubleshooting Guide

❌MCP Tools Not Showing

Solution: Ensure you fully quit and restarted Claude Desktop. Check that Node.js is installed and accessible.

⚠️Connection Errors

Solution: Verify internet connection and that npm can access the @ruv/swarm package. Try running npx @ruv/swarm@latest in terminal first.

🐌Slow Performance

Solution: The first run might be slower as packages are downloaded. Subsequent uses will be much faster.

💻Command Not Found

Solution: Ensure Node.js and npm are properly installed. You may need to restart your terminal/system after installing Node.js.
