# Screenshots Inventory

Place screenshots in `media-server-stack/docs/images/` using the names below so all docs render correctly.

Required images:
- `architecture.png` — high-level diagram
- `webui-setup.png` — Setup tab
- `webui-setup-generate-env.png` — Setup tab after Generate Environment
- `webui-management.png` — Management tab
- `webui-monitoring.png` — Monitoring tab
- `webui-logs.png` — Logs tab
- `webui-deploy.png` — Deploy in progress
- `health-check.png` — Health endpoint output or UI view
- `compose-status.png` — Compose ps output
- `webui-endpoint-tests.png` — Output of `test-webui-endpoints.sh`
- `traefik-dashboard.png` — Traefik dashboard
- `secrets-directory.png` — Example secrets directory contents
- `cli-setup.png` — CLI interactive prompt
- `cli-validation.png` — CLI validate-only example
- `cli-dry-run.png` — CLI dry run example

How to capture:
- Use your OS screenshot tool on the running WebUI and terminal.
- Save images as PNG into `media-server-stack/docs/images/`.
- Keep file names exactly as listed above.
