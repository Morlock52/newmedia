## 🚀 **HOW TO DEPLOY**

### Quick Start (Recommended)
```bash
# 1. Clone or navigate to project
cd /Users/morlock/fun/newmedia

# 2. Build the container
docker build -f Dockerfile.ultimate-single-container-2025-fixed \
  -t ultimate-media-server:2025 \
  --platform linux/amd64 .

# 3. Run with Docker Compose
docker-compose -f docker-compose.ultimate-single-container-2025.yml up -d

# 4. Access the dashboard
open http://localhost:3000
```

### Alternative: Use Deployment Script
```bash
./deploy-ultimate-single-container-2025.sh
```
